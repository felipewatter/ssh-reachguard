# Referências utilizadas

1. OpenBSD OpenSSH `sshd(8)`, seção **AUTHORIZED_KEYS FILE FORMAT**: https://man.openbsd.org/sshd
2. OpenBSD OpenSSH `ssh-keygen(1)`: https://man.openbsd.org/ssh-keygen
3. RFC 4253 (SSH Transport Layer Protocol): https://datatracker.ietf.org/doc/html/rfc4253
4. RFC 4716 (SSH Public Key File Format): https://datatracker.ietf.org/doc/html/rfc4716
5. GitHub, Reviewing your SSH keys: https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/reviewing-your-ssh-keys
6. jtesta/ssh-audit — abordagem complementar: https://github.com/jtesta/ssh-audit
7. SARIF v2.1.0: https://docs.oasis-open.org/sarif/sarif/v2.1.0/sarif-v2.1.0.html
8. NIST SP 800-53 Rev. 5 — Access Control: https://csrc.nist.gov/pubs/sp/800/53/r5/upd1/final

A implementação não reproduz nem copia código dos projetos de referência. As especificações servem como fontes conceituais e para delimitar corretamente as limitações do nosso subconjunto de análise.
